설정
Gemini API 키를 입력하면 브라우저에 저장돼서 다음에도 자동으로 쓰여. 키는 aistudio.google.com/apikey 에서 무료로 발급받을 수 있어.
"구글 시트로 내보내기"를 쓰려면 구글 클라우드 콘솔에서 만든 OAuth 클라이언트 ID가 필요해. (설정 방법은 별도로 안내)
"구글 시트로 내보내기"는 아래 스프레드시트의, 채널별로 지정한 탭(gid)에 새 행으로 바로 쌓여(창은 새로 열지 않음). 채널의 gid를 비워두면 그 채널은 대신 새 시트를 만들어서 채워.
